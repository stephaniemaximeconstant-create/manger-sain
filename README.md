# Manger-sain

## Membres du groupe: Bernie Tajuste, Stéphanie Constant Maxime, Wilda Malluta Saintil

## App description
Application pour les personnes qui veulent manger de bon plats afin de garder leur corps en bonne santé, des repas sans additifs, pour ceux qui souhaitent manger sainement,et qui permet aussi de passer des commandes.

## General App Attributes
- Catégorie: Gastronomie
- Les utilisateurs peuvent commander des nourritures, bien adaptées par exemple pour les personnes diabétiques.
- Story: Pour aider les personnes à bien se nourrir, des nourritures avec moins de graisses possibles.

  ------------------

  ## User Story
  - les utilisateurs peuvent se connecter sur cette application pour rechercher des restaurants qui preparent de bon plat sain
  - les utilisateurs peuvent retrouver des menus personnalises en fonction de leurs besoins comme: Gastro-intestinal, diabetique, cardiovasculaire.
  - les utilisateurs peuvent passer des commandes et faire des reservations
